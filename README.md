# SheRise TN — Women Empowerment Platform for Tamil Nadu 🌸

> **“Your safety. Your skills. Your sovereignty.”**  
> *“உங்கள் பாதுகாப்பு. உங்கள் திறன். உங்கள் இறையாண்மை.”*

SheRise TN is a mobile application initiative dedicated to empowering women across Tamil Nadu through accessible safety resources, certified skill-building opportunities, and strong community sisterhood.

---

## 📱 Included Screens

### 1. Animated Splash Screen
- **Official SheRise TN Branding**: High-definition emblem with soft atmospheric sky glow and drifting mist.
- **Dynamic Shimmer Loading Bar**: Smooth cubic-bezier entrance animation with Tamil/English brand caption.
- **Zero Distraction**: Clean transition straight into the onboarding experience.

### 2. Finalized Empowerment Onboarding Screen
- **Language Switcher**: Instant live toggle between English and Tamil (`[ EN | தமிழ் ]`).
- **Official Brand Header**: Full SheRise TN typography and emblem artwork.
- **Headline & Tagline**: Bold typography highlighting women empowerment in Tamil Nadu.
- **Empowered Woman & Landscape Illustration**: Perfectly fitted Tamil Nadu landmark hero artwork (temple gopurams, rising sun, and natural landscape).
- **Four Core Feature Cards**:
  - 🛡️ **Stay Safe** (*பாதுகாப்பாக இருங்கள்*) — Emergency & support services
  - 🎓 **Skill Up** (*திறன் பெறுங்கள்*) — Free certifications & learning
  - 💼 **Grow Career** (*தொழில் தொடங்குங்கள்*) — Micro-grants & job placements
  - 🤝 **Connect** (*இணையுங்கள்*) — Community sisterhood & guidance
- **Pagination Indicator**: Interactive 3-dot slide navigator.
- **Primary Action**: **Get Started →** pill button with tactile gradient and press feedback.
- **Secondary Action**: **Watch Introduction** pill button with native HTML5 video player modal.
- **Botanical Waves Flourish**: Lavender and purple decorative baseline with seamless zero-scroll mobile responsiveness.

## 🛠️ Tech Stack

- **Frontend**: Vanilla JavaScript (ES Modules), Semantic HTML5, Modular CSS3
- **Build Tool**: [Vite](https://vitejs.dev/)
- **Mobile Packaging**: [Capacitor](https://capacitorjs.com/) (Android)
- **Typography**: Google Fonts (*Outfit*, *Inter*, *Noto Sans Tamil*)

## 🚀 Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) (v18 or higher recommended)
- `npm`

### Installation

```bash
# Clone the repository
git clone https://github.com/Pandeeswaran26/SheRise_TN.git

# Navigate to project directory
cd SheRise_TN

# Install dependencies
npm install

# Start development server
npm run dev
```

### Build for Production

```bash
npm run build
```
